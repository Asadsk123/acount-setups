Install troubleshooting

"Install unknown apps" is blocked

On the block screen tap Settings → turn on Allow from this source for the browser/Files app you opened the APK from → go back → Install. You do this once per source.

Xiaomi / POCO / Redmi (HyperOS / MIUI): "App not installed" or a security scan

HyperOS scans sideloaded apps. On the warning, look for More details → Install anyway. If installation via a cable/adb shows INSTALL_FAILED_USER_RESTRICTED, that is the "Install via USB" developer setting — for a normal file install you do NOT need it; use the download + tap flow instead. Enabling "Install via USB" on Xiaomi requires a Mi account sign-in.

APK won't open / "no app to open this file"

Use a file manager (Files) to open it from the Downloads folder, or re-download.

Old HRAPP version already installed

This app (com.hrapp.remote) installs alongside any older com.hrapp.agent build. To update this one, just install the newer APK over it — same signing key, higher version, no uninstall needed.

Update conflict / "app not installed as package conflicts"

A different-signature build of the same package is installed. Uninstall that one, then install this.

Not enough storage / unsupported Android

The app needs ~2 MB free and Android 8.0 (API 26) or newer.
We never ask you to disable Play Protect or bypass Android security. If your device policy blocks installs, that policy must be changed by you (the device owner) in Settings.
