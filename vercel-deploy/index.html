Install steps

  1. Tap the download button above.
  2. Open the downloaded file (Downloads / notification).
  3. If Android says "install unknown apps" is blocked, tap Settings on that screen and turn on "Allow from this source" for your browser, then go back.
  4. Tap Install.
  5. Open HRAPP Remote, allow the permissions it asks for, and enter the pairing address shown by your controller.

Permissions this app uses (all optional, asked only when you use the feature)

Location, Microphone, Camera — for the matching remote features (Android shows its normal privacy indicators).
Notification access, Accessibility, Device admin — enabled by you in Settings, each explained in the app.
None of these are silent; you grant each one yourself.
